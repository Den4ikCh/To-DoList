# To-Do List

Учебный проект — веб-приложение для управления задачами, написанное на Java с использованием Spring Boot.

## Технологии
- Java 17+
- Spring Boot (Spring Web)
- База данных (SQL)
- HTML, CSS
- Maven

## Функционал
- Создание задач
- Просмотр списка задач
- Изменение статуса задачи
- Удаление задач
